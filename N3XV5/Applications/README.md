# Native peripheral applications

Each application will have a separately signed, checksummed build for its
supported OS: Windows .exe, Linux .deb, macOS .dmg (containing .app).
The Live ISO includes the Linux builds of selected apps.

Planned application IDs (not installed, not implemented by this directory):
- nexus-terminal
- remote-explorer
- network-inspector
- iatb-dashboard
- github-manager

Their manifests will be added only when builds and integration are real.
